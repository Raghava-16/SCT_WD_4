# RESPONSIVE_LANDING_PAGE

This repository contains a Responsive Landing Page Web Application developed using HTML, CSS, and JavaScript to practice frontend web development concepts including responsive design, DOM manipulation, fixed navigation systems, scroll effects, hover animations, and interactive UI development.

## Task Objective

To develop a modern and fully responsive landing page with an interactive navigation menu that changes style during scrolling and hovering, while maintaining smooth navigation and a visually appealing user interface across all devices.

## Tools Used

- HTML5  
- CSS3  
- JavaScript  
- DOM Manipulation Techniques  
- CSS Transitions & Animations  
- Responsive Web Design  

## ✨ Features Included

- Fully Responsive Landing Page  
- Fixed Navigation Menu  
- Scroll-Based Navbar Color Change  
- Hover Effects on Navigation Links  
- Smooth Scrolling Navigation  
- Interactive UI Design  
- Mobile-Friendly Layout  
- Modern Hero Section  
- Responsive Cards Section  
- Smooth Transition Animations  
- Stylish Button Hover Effects  
- Clean and Professional Interface  
- Dynamic Navigation Styling  
- Multi-Section Webpage Layout
